## When something is wrong

- **The project template cannot restore `twblazor`:** the requested twblazor version may not be indexed on NuGet yet. Retry after it is published, or install the same version in a manually created app.
- **Components render with no styling:** `input.css` is missing an `@source` line for `Theme.cs`, or `output.css` was not rebuilt after `Theme.cs` changed. With WebAssembly, the `@source` paths must reach into `{YourProjectName}.Client`.
- **`InvalidOperationException: No Tw...Theme has been configured on the theme`:** the component was not ticked when `Theme.cs` was generated. Regenerate it at https://twblazor.com/theme with the component ticked and replace the whole file.
- **Toasts or dialogs never appear:** `<TwToastProvider />` and `<TwDialogProvider />` must be in `MainLayout.razor`, which must render interactively. With WebAssembly that layout lives in the client project.
- **WebAssembly build cannot find `Theme`:** the host project's `Program.cs` needs `using {YourProjectName}.Client;`, and both projects need the twblazor package.
- **Icons show as empty squares:** the Bootstrap Icons stylesheet link from step 3 is missing from `App.razor`.
