# twblazor

> twblazor is a free, open source library of Tailwind CSS components for Blazor (.NET), installed from NuGet as the `twblazor` package. It works in Blazor Web Apps using Interactive Server or Interactive WebAssembly render modes. Components are named `Tw*` (for example `TwButton`, `TwTextfield`, `TwDataTable`) and are styled entirely by a `Theme.cs` file that lives in the consuming app and is generated by the Theme builder at https://twblazor.com/theme.

This file is for AI assistants helping developers build apps with the twblazor NuGet package. Follow it exactly. twblazor is NOT MudBlazor, Radzen, Blazorise, Bootstrap or Flowbite: do not use their component names, parameters, services or setup steps. When unsure whether a component or parameter exists, read that component's page below rather than guessing. Every page linked below is plain Markdown and lists the component's examples, keyboard navigation, theme and every parameter it accepts. The same page as HTML is at the same address without `.md`.

## Rules for AI assistants

- The theme MUST come from the Theme builder at https://twblazor.com/theme, or be the default `Theme.cs` shown on https://twblazor.com/get-started.md. Never write a `Theme.cs` from scratch, never invent theme classes or properties (for example `TwButtonTheme` members), and never restructure the generated file.
- To change brand colours, surfaces, rounding, shadows, the default input or button style, or which components are included, go back to https://twblazor.com/theme, change the settings, press "Generate Theme" and replace the whole `Theme.cs` with the new output. Do not hand-edit colours or class strings in the generated file as a substitute for regenerating it.
- The generated `Theme.cs` only contains themes for the components ticked on the builder's "Components" tab. Using a component whose theme was left out throws `InvalidOperationException: No Tw...Theme has been configured on the theme`. The fix is to regenerate the theme with that component ticked, not to write the missing theme by hand.
- The Theme builder's file exposes `Theme.CreateTheme`. The default theme on Get Started exposes `Theme.CreateDefaultTheme`. Register whichever one the file actually contains: `builder.Services.AddTwBlazor(_ => { }, Theme.CreateTheme);`
- twblazor ships NO pre-built stylesheet. Tailwind cannot read classes from a .dll, so the app's own Tailwind build must scan `Theme.cs` with an `@source` directive. If components render unstyled, the cause is almost always a missing `@source` for `Theme.cs` or a stale `output.css`.
- Customise individual instances with component parameters (`Color`, `Variant`, `Dense`, `Class`, and so on) and enums from `TwBlazor.Enums` (for example `Color.Primary`, `ButtonVariant.Outlined`). Do not add global CSS overrides for twblazor's internal markup.
- Toasts and dialogs need `<TwToastProvider />` and `<TwDialogProvider />` in an interactively rendered layout (`MainLayout.razor`), never in `App.razor`.
- Keep the accessibility features the components provide: give inputs a `Label`, give icon-only buttons an accessible label, and do not remove focus styles.

## Getting started

Full guide with both hosting models: https://twblazor.com/get-started.md

1. Create a Blazor Web App:
   - Interactive Server: `dotnet new blazor -o {YourProjectName}`
   - Interactive WebAssembly: `dotnet new blazor -o {YourProjectName} --interactivity WebAssembly` (this creates a host project `{YourProjectName}` and a client project `{YourProjectName}.Client`)
2. Install the package. With WebAssembly, install it in BOTH projects.
   ```bash
   dotnet add package twblazor --version {{version}}
   ```
3. In `Components/App.razor` (always in the host project) add to `<head>`:
   ```html
   <link rel="stylesheet" href="@Assets["_content/twblazor/icons/bootstrap-icons.min.css"]">
   <link rel="stylesheet" href="@Assets["css/output.css"]" />
   ```
   and before the Blazor script at the end of `<body>`:
   ```html
   <script src="@Assets["_content/twblazor/js/twblazor.js"]"></script>
   ```
   `css/output.css` is the app's own Tailwind build from step 8, so it 404s until then.
4. Add to `_Imports.razor` (`Components/_Imports.razor` for Server, `{YourProjectName}.Client/_Imports.razor` for WebAssembly):
   ```razor
   @using TwBlazor.Components
   @using TwBlazor.Enums
   @using TwBlazor
   ```
5. Add the providers to the top of `MainLayout.razor` (`Components/Layout/MainLayout.razor` for Server, `{YourProjectName}.Client/Layout/MainLayout.razor` for WebAssembly):
   ```razor
   <TwToastProvider />
   <TwDialogProvider />
   ```
6. Generate a theme at https://twblazor.com/theme and save it as `Theme.cs` at the root of the project that compiles the components: `{YourProjectName}` for Server, `{YourProjectName}.Client` for WebAssembly. See the rules above.
7. Register the services in `Program.cs`. With WebAssembly, do this in BOTH `Program.cs` files and add `using {YourProjectName}.Client;` to the host project's.
   ```csharp
   using TwBlazor;

   builder.Services.AddTwBlazor(_ => { }, Theme.CreateTheme);
   ```
8. Build Tailwind CSS (v4, Tailwind CLI) from the solution root:
   ```bash
   npm init -y
   npm install tailwindcss @tailwindcss/cli
   ```
   Create `{YourProjectName}/wwwroot/css/input.css`. Server:
   ```css
   @import "tailwindcss";

   @source "../../**/*.razor";
   @source "../../Theme.cs";
   ```
   WebAssembly (the sources must reach into the client project):
   ```css
   @import "tailwindcss";

   @source "../../**/*.razor";
   @source "../../../{YourProjectName}.Client/**/*.razor";
   @source "../../../{YourProjectName}.Client/Theme.cs";
   ```
   Then copy the keyframes (`tw-wave`, `tw-icon-pulse`, `tw-rating-pop`) from step 8 of https://twblazor.com/get-started.md into the end of `input.css`. They power `TwSkeleton`'s wave, `TwProgress`'s shimmer, `TwIcon`'s pulse and `TwRating`'s pop animations.
   Build it (add `--watch` while developing):
   - Server: `npx @tailwindcss/cli -i ./wwwroot/css/input.css -o ./wwwroot/css/output.css`
   - WebAssembly: `npx @tailwindcss/cli -i ./{YourProjectName}/wwwroot/css/input.css -o ./{YourProjectName}/wwwroot/css/output.css`
9. Check it works with a page using `@rendermode InteractiveServer` (or `InteractiveWebAssembly`, placed in the client project):
   ```razor
   <TwAlert Color="Color.Success">It works.</TwAlert>
   <TwButton Label="@($"Clicked {count} times")" Color="Color.Primary" OnClick="() => count++" />
   <TwSwitch @bind-Value="enabled" Label="Enabled" Color="Color.Primary" />

   @code {
       private int count;
       private bool enabled;
   }
   ```
