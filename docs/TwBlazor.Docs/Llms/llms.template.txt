# twblazor

> twblazor is a free, open source library of Tailwind CSS components for Blazor (.NET), installed from NuGet as the `twblazor` package. The fastest way to create a new app is the `TwBlazor.Templates` .NET tool: `dotnet tool install -g TwBlazor.Templates`, then `twblazor new MyApp -i wasm -t dashboard`. It creates the solution, theme, Tailwind build and dashboard, sidebar or navbar layout. For an existing app, install the `twblazor` package and follow the manual steps. It works in Blazor Web Apps using Interactive Server or Interactive WebAssembly render modes. Components are named `Tw*` (for example `TwButton`, `TwTextfield`, `TwDataTable`) and are styled entirely by a `Theme.cs` file that lives in the consuming app and is generated by the Theme builder at https://twblazor.com/theme.

This file is for AI assistants helping developers create apps with the twblazor project template and build them with the twblazor NuGet package. Follow it exactly. twblazor is NOT MudBlazor, Radzen, Blazorise, Bootstrap or Flowbite: do not use their component names, parameters, services or setup steps. When unsure whether a component or parameter exists, read that component's page below rather than guessing. Every page linked below is plain Markdown and lists the component's examples, keyboard navigation, theme and every parameter it accepts. The same page as HTML is at the same address without `.md`.
